# LogCollector

**Empfohlen.** Ohne diese Funktion speichert jede Komponente ihre Hinweise und Meldungen nur für sich selbst.

Der LogCollector führt alle Meldungen der verschiedenen Komponenten an einem zentralen Ort zusammen. So behältst du leicht den Überblick, falls Fragen oder Probleme auftreten.

In der WebUI lädst du die gesammelten Logs dann mit wenigen Klicks als ein Archiv
herunter, siehe [Logs herunterladen](usage.md).
