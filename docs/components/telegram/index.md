# Telegram

**Bei Bedarf.** Hannah funktioniert auch komplett ohne Telegram — diese Komponente
erlaubt zusätzlich, Hannah per Telegram-Chat anzusprechen: Text rein, Text oder Sprache
zurück. Läuft als eigener Prozess mit eigenem Lebenszyklus, damit ein Absturz hier nicht
Hannah Core mitreißt.

Damit Hannah weiß, wer schreibt, verknüpfst du dein Telegram-Konto mit deinem
Hannah-Nutzer (siehe [Verknüpfte Konten](../../manual/users.md#telegram)). Ohne
Verknüpfung behandelt Hannah dich wie einen Gast — Geräte mit einer
[Mindest-Vertrauensstufe](../../manual/smart-home-integration.md#gerate-schutzen) kannst
du dann weder per Nachricht noch über das Gerätemenü schalten.
